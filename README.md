# برنامج إدارة محل الوميتال

برنامج سطح مكتب عربي لإدارة المنتجات والمخزون والعملاء وفواتير البيع والتحصيل والأقساط، باستخدام قاعدة بيانات محلية.

## التشغيل

يتطلب تشغيل ملفات Python مباشرة Windows وPython 3.10 أو أحدث مع دعم Tkinter، والحزم الموجودة في `requirements.txt`.

1. افتح PowerShell في مجلد البرنامج.
2. شغّل:

   ```powershell
   python app.py
   ```

تُحفظ قاعدة البيانات افتراضيًا في `%LOCALAPPDATA%\AlumetalManager\business.db`. يمكنك تغيير مكانها من زر **مكان قاعدة البيانات**؛ عند اختيار ملف جديد ينسخ البرنامج بياناتك الحالية إليه، وعند اختيار ملف موجود يسألك قبل التبديل إليه. خذ نسخة احتياطية دوريًا.

تُحفظ ملفات فواتير PDF في مجلد `Invoices` بجوار قاعدة البيانات الحالية.

## الوظائف

- شريط قوائم علوي للأقسام والملف واللغة وحول البرنامج، مع تبديل بين العربية (من اليمين لليسار، وتظهر «الرئيسية» وأول أعمدة الجداول جهة اليمين) والإنجليزية (من اليسار لليمين). يُحفظ اختيار اللغة تلقائيًا.
- تعرض نافذة «حول» أن البرنامج تمت برمجته وتصميمه بواسطة الأستاذ أحمد دهيس، وأرقام التواصل المسجلة.
- إضافة المنتجات يدويًا وتسجيل التصنيف والوحدة والتكلفة وسعر البيع والرصيد.
- إدارة بيانات العملاء.
- إنشاء فاتورة، وتحديث المخزون تلقائيًا، وتسجيل المدفوع والمتبقي.
- البحث عن المنتج بالاسم داخل الفاتورة؛ تظهر كل المنتجات عند فتح خانة البحث، ثم تتحدث النتائج فور الكتابة مع بقاء المؤشر في خانة البحث.
- فتح الفاتورة للطباعة من المتصفح، بتنسيق نظيف دون ترويسة أو تذييل المتصفح مثل مسار الملف، مع إمكانية اختيار الطابعة أو الحفظ PDF.
- تسجيل التحصيل والأقساط، ومراجعة الديون المفتوحة.
- إنشاء الفاتورة كملف PDF عربي وفتح محادثة واتساب للعميل؛ يفتح المستكشف على الملف لتقوم بإرفاقه يدويًا ثم الضغط على إرسال داخل واتساب. لا يتيح رابط واتساب إرفاق الملفات أو إرسالها تلقائيًا.
- تنبيهات متابعة للفواتير المفتوحة عندما يبلغ المتبقي الحد المالي أو يتجاوزه ويمر عدد الأيام المحدد دون تحصيل. الإعداد الافتراضي ٥٠٠٠ جنيه و١٠ أيام، ويمكن تغييره من تبويب التنبيهات.
- تصدير الفواتير إلى Excel لفترة تاريخية تختارها، في أوراق منفصلة للفواتير والأصناف والدفعات.
- عرض الفواتير وتفاصيل الأصناف وسجل الدفعات، مع تسجيل تحصيل وطباعة الفاتورة من شاشة المبيعات أو الديون.
- فتح كشف حساب العميل من شاشة العملاء لمراجعة مشترياته وفواتيره وإجماليات المدفوع والمتبقي، ثم فتح تفاصيل أي فاتورة أو طباعتها.
- طباعة كشف مشتريات وحساب كامل للعميل يتضمن تفاصيل الفواتير والأصناف والدفعات وإجمالي المبلغ المتبقي عليه.
- عرض إجمالي المبيعات والأرباح والديون والكميات المتاحة.
- تخصيص اسم المحل المطبوع على الفاتورة.

العملة المستخدمة هي الجنيه المصري. يُحسب الربح على أساس سعر التكلفة المسجل وقت البيع. لإضافة وارد جديد إلى المخزون، عدّل رصيد المنتج من شاشة المنتجات.

## نسخة ويندوز مستقلة

شغّل `بناء نسخة ويندوز.bat` على جهاز Windows لإنشاء `dist\AlumetalManager.exe`. انسخ ملف EXE إلى الجهاز الآخر وشغّله مباشرة دون تثبيت Python أو مكتبات. مسار قاعدة البيانات وإعداداته يُحفظان لكل مستخدم على حدة؛ الأجهزة لا تتزامن تلقائيًا. يمكن اختيار قاعدة البيانات يدويًا من داخل البرنامج على كل جهاز.

لتثبيت متطلبات تشغيل ملفات Python وبناء EXE:

```powershell
python -m pip install -r requirements.txt
```

## ملفات المشروع

- `app.py` — الواجهة الرئيسية ووظائف البرنامج.
- `database.py` — قاعدة البيانات المحلية وإعداداتها.
- `localization.py` — نصوص العربية والإنجليزية.
- `update_manager.py` و`version.py` و`github_config.py` — فحص تحديث GitHub والتحقق من ملف التحديث وإصداره.
- `excel_export.py` و`pdf_invoice.py` — تصدير Excel وإنشاء ملفات PDF.
- `docs\index.html` — صفحة المشروع المنشورة عبر GitHub Pages.
- `.github\workflows` — بناء إصدارات Windows ونشر صفحة المشروع.

## رفع المشروع وتفعيل صفحة GitHub

أنشئ مستودعًا عامًا وفارغًا باسم `AlumetalManager` في حساب `ahmeddahees`، ثم افتح PowerShell في مجلد المشروع ونفّذ:

```powershell
git init -b main
git remote add origin https://github.com/ahmeddahees/AlumetalManager.git
git add .
git status --short --ignored
git commit -m "Initial project upload"
git push -u origin main
```

راجع `git status --short --ignored` قبل الإرسال؛ يجب أن تظهر قاعدة البيانات ومجلد `New folder` وملفات الفواتير ضمن الملفات المستبعدة. ملف `.gitignore` يستبعد كذلك ملفات البناء والتصدير.
إذا لم يتعرف PowerShell على الأمر `git`، ثبّت Git for Windows أو GitHub Desktop ثم افتح PowerShell من جديد.

بعد رفع الملفات، من **Settings → Pages** اختر **GitHub Actions** كمصدر النشر. ستنشر آلية GitHub Actions الصفحة على:

`https://ahmeddahees.github.io/AlumetalManager/`

قد يستغرق أول نشر عدة دقائق. صفحة المشروع ورابط تنزيل أحدث إصدار لن يعملا قبل إنشاء المستودع ونشر الملفات.

## نشر تحديث للبرنامج

بعد رفع المشروع، انشر أول إصدار بالوسم `v1.0.0`. للإصدارات التالية ارفع التغييرات ثم أنشئ وادفع وسمًا جديدًا بصيغة `vMAJOR.MINOR.PATCH`، مثل:

```powershell
git tag v1.0.1
git push origin v1.0.1
```

سيشغّل GitHub الاختبارات، ويبني نسخة Windows مستقلة، وينشر ملف EXE وملف بصمة SHA-256 في صفحة **Releases**. يفحص البرنامج وجود تحديث عند بدء التشغيل ويطلب موافقتك قبل تنزيله وتثبيته؛ ويمكن بدء الفحص يدويًا من قائمة **ملف → بحث عن تحديث**. قاعدة البيانات لا تُستبدل أثناء تحديث البرنامج. يتطلب التثبيت التلقائي تشغيل نسخة EXE المنشورة، وليس تشغيل `app.py` مباشرة.

يجب استبدال النسخة القديمة يدويًا بأول نسخة تحتوي على المحدث؛ بعد ذلك يمكن للبرنامج تثبيت الإصدارات المنشورة تلقائيًا بموافقتك.
